## Concrete audit findings retained

- [JetBrains slides_test.py](https://github.com/JetBrains/skills/blob/e0f258b5cfed145015cb3e48da9a97947f7c4ed7/slides/scripts/slides_test.py) checks enlarged-canvas edge pixels. It can print `ERROR` without a nonzero exit status. Inspect findings, not just exit code; it does not detect every internal overlap or text-box clipping.
- Font presence, a renderer's actual font selection, and native PowerPoint fidelity are distinct checks.
- Original sources can change or disappear while search caches still describe old files. Verify the current file tree or pin a reviewed commit before adopting code.
- Rich visuals, editable objects and narrative quality are separate capabilities. Select the required combination for the user rather than ranking every skill on a single “best” label.

## What this installed skill contains

A PowerPoint-first director, a reference-analysis workflow, a composition playbook, native/mixed/image output contracts, host-aware authoring guidance, separate content/visual/file QA, and a read-only local dependency probe. It routes to installed engines; invoking it does not install any candidate, change agent configuration, add hooks, or publish work.
